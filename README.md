# PhonePad 手机蓝牙手柄

[下载最新版 APK 和 Windows Xbox 转换器](https://github.com/OceandeepGavin/PhonePad-Releases/releases/latest)

手机首次用浏览器下载 APK 安装，之后在 App 的连接设置中点“检查更新”。最低 Android 9，需要系统支持 Bluetooth HID Device。

手机与电脑蓝牙配对 → App 启用手柄 → 选择实际电脑 → 连接。通用 HID 游戏可直接使用；需要 XInput 时，运行 Windows 转换器并安装 ViGEmBus。Windows 压缩包内有详细说明。

当前均为测试版。本仓库只用于发布安装包和更新信息。
